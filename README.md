# CTS Summer Internship 2025

This repository is a record of my work during the summer 2025 internship at Core Techs Solutions, Inc. It started as a training-focused workspace covering core software engineering fundamentals, then expanded into prototype work around data structures, Java desktop applications, and a later computer vision effort related to book-state assessment.

## What This Repo Covers

- Weekly training exercises in C and Java
- Small console and browser-based practice projects
- A multi-step hash table visualizer explored through desktop and backend implementations
- A placeholder reference to the book-state assessment project I continued after the internship in a part-time role

## Internship Progression

### Week 1: Foundations

The first week focused on programming basics, algorithmic thinking, and getting comfortable solving small problems in both C and Java.

Examples in this folder include:

- String reversal and bit manipulation
- Sliding window and conditional sorting exercises
- Introductory Java class design and aggregation tasks

### Week 2: Problem Solving and OOP Practice

The second week moved toward structured problem solving and simple application design.

Highlights:

- C implementations for coin change, N-Queens, and graph traversal
- A small Java banking system model
- A basic bookstore management exercise with console and HTML pieces

### Weeks 3 and 4: Hash Table Visualization Work

A larger thread through the internship was building and experimenting with hash table visualizers across different environments.

This repository includes:

- A Java Swing implementation for interactive visualization
- A Java desktop prototype using Nuts
- A Spring Boot backend exposing hash table operations for a fuller application setup

That work helped me practice:

- Data structure implementation
- UI-oriented thinking for technical concepts
- API design for interactive tooling
- Moving the same idea across multiple stacks

### Book-State Assessment Project

During the internship, and later after being recruited part-time, I worked on a computer vision project related to assessing the state of books using deep learning models.

Because that work is not public, this repository only references it at a high level. I want it represented here because it was an important part of my progression from training exercises to applied engineering work.
