### Week 3-4: Multi-Platform Interactive Hash Table Visualizer

**Project Description:**
A comprehensive multi-platform application that provides an interactive visualization tool for understanding hash table data structures and their operations.

**Features:**
- Interactive visualization of hash table operations (insert, delete, search)
- Support for multiple hash functions
- Real-time animation of collision resolution
- Cross-platform compatibility (Web, Desktop)

**Focus Areas:**
- Data structure visualization
- User interface design
- Multi-platform development
- Interactive web applications

**Technologies:** 
- **Java** (80.5%) - Core logic and desktop application
- **C** (16.8%) - Performance-critical components
- **HTML** (2.7%) - Web interface and visualization

**Deliverables:**
- Functional hash table visualizer
- Web-based interactive interface
- Documentation and user guide
